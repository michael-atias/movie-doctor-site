How to sync an SRT file to a video

Updated: 25 November 2026

You have a video and an SRT subtitle file, and they do not line up. Before fixing it, it helps to see how the file works, because that explains why each fix works.

How an SRT file works

It is a plain text file. Each subtitle is a number, a line of times, and the text:

12
00:01:04,250 --> 00:01:06,900
So how did the channel start?

The times are hours:minutes:seconds,milliseconds. The player shows the line at exactly those times and knows nothing about what is said in the video. So if the times are wrong, the player cannot fix them by itself.

Step 1: find out which problem you have

  • The same offset from start to end: subtitles too early or too late.
  • The offset grows or jumps along the way: subtitles that drift.

To tell, check three points: near the start, the middle and near the end. If the gap is the same at all three, it is a fixed offset.

Step 2: fix and save

Open the SRT in the free Subtitle Edit, fix it for your kind of problem, and save. Give it the same name as the video (for example lesson-3.mp4 and lesson-3.srt) in the same folder, so most players load it by themselves.

Tip: subtitles inside the file

If you want the subtitles to work on a TV without a separate file, you can put them inside the video file (MKV or MP4) without re-encoding the picture. Then there is one file that simply plays.
